How to run the Demo in Emulator?

- on Windows download the HT-1080Z emulator from here: http://gaia.atilia.eu/download/ht1080z1.7.0.zip
- run the emulator then press ALT+Q
	- select Configuration: HT 1080Z/64-model 3
	- attach fafdem.cas using ALT+T
- enetr memory size then go to System mode then load the demo then run it from 17129 address
	- MEMORY SIZE? - 49152
	- >SYSTEM <enter>
	- *? FAFDEM <enter>
	- *? /17129 <enter>
