	- select Configuration: HT 1080Z/64-model 3
	- attach COMMAN.CAS using ALT+T
- enter memory size then go to System mode then load the game then run it from 17129 address
	- MEMORY SIZE? - 49152
	- >SYSTEM <enter>
	- *? COMMAN <enter>
